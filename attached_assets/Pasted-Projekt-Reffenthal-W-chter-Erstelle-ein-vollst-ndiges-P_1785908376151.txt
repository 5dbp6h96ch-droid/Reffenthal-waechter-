Projekt: Reffenthal-Wächter

Erstelle ein vollständiges Python-Projekt für Replit mit GitHub-Integration.

Ziel

Ein automatischer Wächter, der Informationen rund um den Reffenthal sammelt und per Telegram verschickt.

Das Projekt soll vollständig in Replit entwickelt werden und automatisch mit GitHub synchronisiert werden können.

⸻

GitHub

Das Projekt soll direkt aus einem GitHub-Repository arbeiten.

Folgende Funktionen sollen vorbereitet werden:

* GitHub Repository klonen
* Änderungen committen
* Änderungen nach GitHub pushen
* README automatisch aktualisieren
* .gitignore erstellen
* GitHub Actions Workflow erstellen
* Projekt jederzeit zwischen Replit und GitHub synchronisieren

Erstelle folgende Dateien:

.github/workflows/watcher.yml
.gitignore
README.md
requirements.txt
